# StudentHub Portal

## 1. Project Overview

StudentHub is a student portal designed to provide students with a single platform
to access important academic information and student-related services.

The portal provides a simple and user-friendly interface where students can log in
and access their dashboard, profile, study materials, timetable, assignments,
results, and other important information.

The project is being developed as a semester-long web development project.

---

## 2. Problem Statement

Students often need to access different types of academic information from
different sources. This can make it difficult to manage study materials,
assignments, timetables, results, and personal information efficiently.

StudentHub aims to provide a centralised platform where students can access
important academic resources and information in one place.

---

## 3. Project Objectives

- To create a centralised student portal.
- To provide easy access to academic information.
- To provide a user-friendly and simple navigation system.
- To allow students to manage and view their profile information.
- To provide access to study materials and course information.
- To provide timetable and assignment information.
- To allow students to view their academic results.
- To provide important university and contact information.

---

## 4. User Roles

### Student

Students are the primary users of the StudentHub portal.

Students can:

- Register for an account.
- Log in to the portal.
- Access the dashboard.
- View and manage their profile.
- Access study materials.
- View their timetable.
- View assignments.
- Check academic results.
- Access university information.
- Contact the university or support team.

### Administrator

The administrator role can be considered for future development.

Administrators may be able to:

- Manage student information.
- Manage courses and study materials.
- Manage assignments.
- Manage timetable information.
- Manage student results.
- Manage portal content.

## 6. Website Pages

### 1. Home Page

The home page is the main entry point of the StudentHub portal.

It contains:

- MY HUB logo
- Welcome message
- Login button
- Sign Up button
- Main image/banner

### 2. Login Page

The login page allows registered students to access their accounts.

It contains:

- Username / Email
- Password
- Login button
- Sign Up link

### 3. Register Page

The registration page allows new students to create an account.

It contains:

- Email ID
- Mobile Number
- Password
- Sign Up button

### 4. Dashboard

The dashboard provides navigation to the main student portal features.

It contains:

- Dashboard
- Time Table
- Study Material
- Assignments
- Results
- Profile
- Home
- About Us
- Contact Us
- Logout

### 5. Profile Page

The profile page displays student information.

It contains:

- Student photo
- Student name
- Student ID
- Email
- Mobile number
- Personal information
- Edit Profile option

### 6. Study Material Page

The study material page provides access to academic resources.

It contains:

- Course / Material 1
- Course / Material 2
- Course / Material 3
- Course / Material 4
- Course / Material 5
- Course / Material 6

### 7. Time Table Page

The timetable page displays the student's academic schedule.

It contains:

- Days
- Time slots
- Subjects
- Class schedule

### 8. Assignments Page

The assignments page allows students to view and manage assignments.

It contains:

- Assignment list
- Subject
- Assignment title
- Due date
- Assignment status
- View Assignment
- Submit Assignment

### 9. Results Page

The results page displays academic performance.

It contains:

- Student name
- Student ID
- Department
- Semester
- Subject
- Internal marks
- External marks
- Total marks
- Grade

### 10. About Us Page

The About Us page provides information about the university.

It contains:

- About University
- University Information
- Centres & Cells
- Examination Cell
- National Service Scheme (NSS)
- Equal Opportunity Cell
- Student's Grievance Redressal Cell
- Innovation & Incubation Centre
- Training & Placement Cell

### 11. Contact Us Page

The Contact Us page allows users to contact the university or support team.

It contains:

- Full Name
- Email
- Subject
- Message
- Send Message
- Address
- Email
- Phone Number
- Office Timing

---

## 7. Navigation Flow

The basic navigation flow of the StudentHub portal is:

Home
→ Login / Register
→ Dashboard

From the Dashboard, students can navigate to:

- Profile
- Study Material
- Time Table
- Assignments
- Results

The Home page also provides access to:

- About Us
- Contact Us
